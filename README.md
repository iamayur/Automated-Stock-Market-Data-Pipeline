# Automated-Stock-Market-Data-Pipeline
Automated Financial Data Pipeline (ETL)

Designed and built a robust ETL pipeline to extract stock market data using Python and REST APIs, processing 1,000+ records daily.

Performed data cleaning and transformation using Pandas, ensuring 100% data integrity before storage.

Automated the daily workflow using GitHub Actions, eliminating the need for manual data updates.

Loaded processed data into a PostgreSQL database/warehouse for downstream analysis.
